# RuView

Camera-free presence sensing for Home Assistant, from the Wi-Fi signals
between your router and small ESP32-S3 boards.

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]
![Experimental][stage-shield]

- Presence, motion and signal sensors for each node, through MQTT discovery.
- No cameras, no microphones, nothing sent to the internet.
- Heart rate and fall detection stay off unless you opt in (both unvalidated).

**Experimental:** not yet measured in a real home. See the Documentation tab
before you start.
